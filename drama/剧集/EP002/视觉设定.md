# EP002 视觉设定

全片是 9:16 竖幅，延续游戏主视觉的国风 HD-2D 动画电影质感，手绘赛璐璐上色：手绘赛璐璐质感，光效层柔和，线条干净，画面统一压一层暖黄、低饱和的午后色调。时间是九月第一个周六的下午，地点是县城高中的男生寝室，镜头始终贴着靠窗那张书桌。

这一集的特殊性在于**光是主角**：前六秒的光是窗外进来的暖光，从第八秒起，画面被屏幕里漫出来的冷白光接管，暖黄与冷白在同一张桌子上交接。所有镜头的色温变化都服从这条线。

## 人物 · 周全

- 识别锚点：十七岁男生，清瘦，肩背略窄；黑色短碎发，发梢压着眉；单眼皮，眼窝浅，下颌线清楚；嘴唇偏薄，静止时嘴角平。
- 本集造型：白底藏蓝领校服短袖，领口与门襟是藏蓝，左袖口有一道同色细边；深蓝运动裤，侧缝一道白条；白色低帮球鞋。本集只入画手、前臂、侧脸与半身。
- 状态变化：从站在桌前摆弄手机，到被白光吓得猛地往后缩、手脚并用往后退、一步没站稳坐倒在地（屁股着地、两手撑在身后、腿摊开），再撑着往后蹭；全程眼睛瞪大、嘴张开，是恐惧不是难受。最后被扫描时定格成愕然：身体不动、一只手还举在半空、嘴微张、眼睛盯住它。
- 画面代称：周全
- 连续性锁：LOCK-ZHOU-UNIFORM《周全校服短袖》（镜头：SHOT-EP002-001、SHOT-EP002-002；图片提示词项：IMG-ZHOU-SHEET）· 锁面：白底藏蓝领校服短袖
- ID：VISUAL-ZHOU

## 人物 · 小白

- 识别锚点：由光凝成的非人形体，通体纯白、半透明、边缘带一点冷蓝；身形比周全矮，悬空时视线与他齐平。一张没有表情的娃娃脸：圆脸、下巴钝，眼睛是两点没有高光的黑，没有眼白，鼻梁与嘴只是极浅的凹，不出现牙齿与舌头。
- 本集造型：白色连帽长袍，兜帽罩住头顶，袍摆垂到小腿，边缘被光烧得略透；背后一对小小的白色羽毛翅膀，羽毛一层压一层、翼骨清晰，羽尖被光照透；胸口一枚圆形核心，淡蓝，外圈缓慢呼吸。
- 状态变化：从一颗白点 → 两点眼 → 整张脸 → 白袍与翅膀成形 → 核心亮起。成形过程中形体不稳，边缘有细小的光屑剥落。本集后半段它会原地转一圈打量房间、上下飘动，并让额头射出一束扇形白光照着周全做扫描。
- 画面代称：小白
- 连续性锁：LOCK-XIAOBAI-FORM《小白白袍兜帽形制》（镜头：SHOT-EP002-002；图片提示词项：IMG-XIAOBAI-SHEET）· 锁面：白袍兜帽、一对白色羽毛小翅膀、胸口淡蓝圆形核心
- ID：VISUAL-XIAOBAI

## 地点 · 书桌角

- 识别锚点：靠北墙的一张旧木纹铁架书桌，桌面偏橙、木纹粗；桌后是那扇旧白漆双开玻璃窗，窗外是梧桐枝叶与过曝的天光；桌上靠左一摞旧书（三四本，封面米黄），右后一只白底蓝边的搪瓷缸；桌角一团缠着的旧充电线。桌子左右两侧是深棕木架单人床，蓝白方格棉被，画面边缘会带进一点被角。**没有衣柜，没有床头架。**
- 本集光态：前段是九月下午从北窗斜进来的暖黄侧光，桌面上有一块亮斑；后段被屏幕的白光压过，暖光退成边缘的暗部，桌面反出冷白色高光。
- 状态变化：桌面上那摞旧书被翻开一角（手机原本压在下面）；充电线从桌角被拽到桌子中央。
- 连续性锁：LOCK-DORM-DESK《书桌与北窗》（镜头：SHOT-EP002-001、SHOT-EP002-002；图片提示词项：IMG-DESK-PLATE）· 锁面：北窗在桌后偏右、旧书在左、搪瓷缸在右后
- ID：VISUAL-DESK

## 道具 · 手机

- 识别锚点：深灰色直板触屏手机，正面几乎整块都是屏幕，屏幕顶部中间一个极小的前摄孔；背面磨砂灰，左上角一个双摄模组（两枚镜头横排 + 一枚小闪光灯），背面中部一块浅凹的指纹区；边框是磨出银亮的塑料边，边角有两处磕痕；底部居中一个 USB-C 接口与两排扬声器开孔，右侧是音量键与电源键。屏幕不亮时是深灰近黑，能反出窗光；四角有细裂纹，贴着一张边缘起泡的旧钢化膜，蒙着一层灰与几道指纹。
- 状态变化：从书摞底下被抽出（背面朝上、屏幕蒙灰）→ 翻正、按电源键不亮 → 插上充电线仍不亮 → 屏幕里自己亮起一粒白点 → 白光炸开、整机悬空、机身边缘发冷光。
- 画面代称：手机
- 连续性锁：LOCK-PHONE《深灰直板触屏手机》（镜头：SHOT-EP002-001、SHOT-EP002-002；图片提示词项：IMG-PHONE-SHEET）· 锁面：深灰直板触屏机身、背面双摄模组、底部充电口
- ID：VISUAL-PHONE

## 道具 · 充电线

- 识别锚点：深灰色的旧充电线，线身有几处折痕、外皮发乌；插头是 USB-C 的小扁头，金属触点发暗；线尾缠成一团，压在桌角。
- 状态变化：被拽直，插进手机尾部的接口，线在桌面上拉出一道弧。
- 画面代称：充电线
- ID：VISUAL-CABLE
