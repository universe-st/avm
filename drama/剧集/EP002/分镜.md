# EP002 分镜

两个镜头，一个 6 秒、一个 8 秒，合计 14 秒。前一镜全在桌面高度：把手机从书摞底下抽出来、按电源、插线、敲屏幕，一件件做完，全是一个人的手感；后一镜从同一格屏幕起跳，白点炸开、手机脱手悬空、光在桌子上面凝成一张脸。两镜之间是同一构图的交叉溶解，不做硬切——因为变化就发生在屏幕上那一点白里。

## 场景站位 · EP002-SC001 · 书桌角

- 固定锚点：北墙那扇旧白漆双开玻璃窗在画面右上；窗下、画面下缘横着那张旧木纹铁架书桌；桌上靠左一摞旧书，右后一只搪瓷缸，桌角一团米白色充电线；桌子左右两侧是木架单人床，画面边缘带进一点蓝白方格被角。房间是木墙木地板，没有衣柜。
- 人物：周全蹲在桌子南侧，身体略朝窗，右手在画面右下入画；他只入画手、前臂、侧脸与肩。
- 轴线：书桌 ↔ 北窗；working side 是桌子南侧（他站的一边），镜头始终在他这一侧，不越过桌面到窗那边去。
- 变化：镜内他从蹲着摆弄手机，到被光逼得抬手后撤。

## SHOT-EP002-001 · 开机

- 来源：EP002-SC001
- 时长：6s
- 目的：把「手机坏了」演成手感——抽出来、按、插、敲，四下都不给回应，最后一下屏幕自己亮了。
- 景别/机位：桌面近景，机位在桌子南侧偏右、俯约二十度；书摞占画面左下，搪瓷缸在右后虚焦，北窗的光从右上方压下来；画面右下是他的前臂与手。
- 运镜：基本固定，只做极缓的推近与极轻的下压，跟着手的动作微调；不摇不甩，让观众把注意力留在屏幕上。
- 起点：周全的右手伸进那摞旧书底下，指尖刚够到手机的边。
- 唯一动作：把手机从书摞下抽出来 → 翻正 → 拇指按电源键 → 再按两下 → 拽过桌角的充电线、插进手机尾部 → 抬起右手用指节敲两下屏幕。
- 终点：他的指节停在屏幕上，屏幕中央浮起一粒白点，白点自己涨大。
- 图片提示词项：IMG-DESK-PLATE《书桌与北窗场景板》（控制：北窗在桌后偏右、旧书在左、搪瓷缸在右后）；IMG-PHONE-SHEET《手机道具板》（控制：深灰直板触屏机身、背面双摄模组、底部充电口）；IMG-ZHOU-SHEET《周全角色板》（控制：手与前臂的体型、校服袖口形制）
- 输入参考图：REF-SHOT001-START（顺序：1）· 剧集/EP002/制作成果/images/SHOT-EP002-001.png《SHOT-EP002-001 起始帧》（用途：起始帧；控制：第一格的构图、书桌陈设、窗与光向、右手入画的位置；不得控制：镜内的按键动作与屏幕亮度变化）
- 视觉依据：《视觉设定.md》·地点「书桌角」（控制：北窗在桌后偏右、旧书在左、搪瓷缸在右后、木墙木地板无衣柜）；道具「手机」（控制：深灰直板触屏机身、背面双摄模组、底部充电口）；道具「充电线」（控制：深灰旧线、USB-C 扁头）

### 冻结关键帧提示词
> 国风 HD-2D 动画电影质感，手绘赛璐璐上色，9:16 竖幅，九月的下午。桌面近景，机位在桌子南侧偏右、俯约二十度：画面左下是一摞三四本旧书，封面米黄、边角卷起，一只手正伸进书摞底下，指尖够到一部深灰色直板触屏手机的边，手机背面朝上，露出一角背面双摄模组；画面右后是一只白底蓝边的搪瓷缸，虚焦；桌后偏右是旧的白色双开玻璃窗，窗框漆面起皮，窗外梧桐枝叶过曝，暖黄的天光从右上压下来，在桌面上留一块亮斑；桌子左右边缘露出深棕木架床的一角与蓝白方格被角。手是十七岁男生的手，清瘦，袖口是白底藏蓝领校服短袖、袖口一道藏蓝细边；桌面陈设与机身形制全程不变：北窗在桌后偏右、旧书在左、搪瓷缸在右后，手机是深灰直板触屏机身、背面双摄模组、底部充电口。手绘赛璐璐质感，光效层柔和，线条干净。画面里只有这一只手，任何时刻都不生成文字、字幕、水印与 logo。

## 场景站位 · EP002-SC002 · 同一张桌子，抬高的视点

- 固定锚点：北窗仍在画面右上，书桌在下缘；手机从桌面升到画面中部偏左，小白悬停在手机正上方；周全的半身在画面右下，仰头。
- 人物：周全只入画肩、侧脸与扬起的手臂；小白全身入画，悬空，脚离桌面约一掌。
- 轴线：小白 ↔ 周全，视线高低差是本镜的核心——它悬在桌上，他瘫坐在地上仰头。镜头在桌子南侧后退并下移，把桌子前方那块地板收进来；后退幅度要小，画面左边必须始终带到他左后方那张木架单人床和蓝白方格被，不能把床拍成一片木板墙。
- 变化：手机从手里脱出、升起；桌面从暖黄被白光压成冷白；小白的形体从一粒白点长成完整的人形。

## SHOT-EP002-002 · 屏幕里的脸

- 来源：EP002-SC002
- 时长：8s
- 目的：让「光里长出一张脸」成为这一节的第一个超现实画面，同时用高低差把「它在上、他在下」讲清楚——他被吓得连连后退、摔坐在地上，不是身体不适。
- 景别/机位：起幅与前一镜同一格（手机在手里、屏幕白点），随后镜头后拉并微微上抬，落到书桌上方的小中景；机位仍在桌子南侧、略低于视平线，朝北窗。
- 运镜：先前推半寸逼近那粒白点，白点炸开的一瞬镜头被光推开——后拉约一米、同时下移并轻微下倾，把手机、桌面和他坐倒在地的那块地板一起收进画面；之后停住，只随小白的成形轻微上摇。
- 起点：他的指节压在屏幕上，屏幕中央一粒白点，白光刚从屏幕边缘漫出来。
- 唯一动作：白点炸开、白光洗过桌面和他的脸 → 手机脱手浮起、机身边缘发冷光 → 他猛地一缩、抬手挡脸、后退两步、脚下一滑坐倒在地，再撑着往后蹭 → 光在手机上方收拢成娃娃脸 → 白袍、兜帽、翅膀与胸口核心成形 → 它悬停俯视他。
- 终点：小白悬停在书桌上方，胸口核心亮着一圈淡蓝；周全瘫坐在书桌前的地板上，两手撑在身后、腿摊开，仰头看它，眼睛瞪大、嘴还张着，脸被光压成半剪影。

> 国风 HD-2D 动画电影质感，手绘赛璐璐上色，9:16 竖幅。桌面近景：一部深灰色直板触屏手机被十七岁男生的手托在掌心，屏幕朝着镜头，背面双摄模组从指缝里露出一角；手机屏幕中央有一粒白点，白光刚从屏幕边缘漫出来，把手指的边缘、袖口的白底藏蓝细边和桌面的一小块木纹照得发亮；桌面上还能看见半截深灰色的旧充电线。背景是旧的白色双开玻璃窗与梧桐枝叶，暖黄的天光被这点白压下去，画面下半部开始转冷。锁定的形制：小白是白袍兜帽、一对白色羽毛小翅膀、胸口淡蓝圆形核心，手机是深灰直板触屏机身、背面双摄模组、底部充电口，他穿白底藏蓝领校服短袖；桌面方位不变——北窗在桌后偏右、旧书在左、搪瓷缸在右后。手绘赛璐璐质感，光效层柔和，线条干净。画面里不出现人物正脸，任何时刻都不生成文字、字幕、水印与 logo。

## 场景站位 · EP002-SC003 · 同一张桌子，同一个地面

- 固定锚点：北窗与书桌仍在画面右侧与下缘，木架床与蓝白方格被在画面左侧；周全坐在地板上，位置承接上一镜的结尾（屁股着地、两手撑在身后、腿摊开）；小白悬在书桌上方的半空中，视线比坐着的他高约一个头。
- 人物：周全全身入画，姿态从「还在往后蹭」定住成「愕然不动」；小白全身入画，兜帽、翅膀、胸口核心都清晰。
- 轴线：小白 ↔ 周全。镜头在桌子南侧、略低于视平线，不越轴；它上下飘动时镜头只做轻微上摇跟随，不剪断两人之间的视线。
- 变化：小白原地转一圈 → 上飘到窗框上沿 → 俯冲到他一臂远 → 升高半米 → 额头射出扇形的扫描光 → 光收回去，他保持愕然。

## SHOT-EP002-003 · 扫描

- 来源：EP002-SC003
- 时长：8s
- 目的：把「它是来办事的，不是来吓人的」演出来——它先打量房间、再上下试探、最后一束光把他从头扫到脚；他全程只剩愕然。
- 景别/机位：中景，机位在桌子南侧、略低于视平线，朝北窗；他坐在地板上的位置占画面下半部，小白悬在画面中部偏上；起幅就是上一镜的最后一帧。
- 运镜：基本固定，只随小白的上下做极缓的上摇与下压；它俯冲到近前时镜头微微后仰，扫光时停住不动，把整束光和他的表情一起框住。
- 起点：小白悬在书桌上方，翅膀开着、核心亮着；周全坐在地上，一只手还举在半空，嘴张着。
- 唯一动作：小白原地慢慢转一圈打量房间 → 上飘到窗框上沿 → 俯冲到他面前一臂远 → 升高半米 → 兜帽下的额头亮起 → 铺开扇形白光，从头往下扫过他 → 光收回，他定住不动。
- 终点：小白悬在他斜上方，核心亮着，微微低头；周全维持愕然的姿势，眼睛瞪大、嘴微张，一动不动。
