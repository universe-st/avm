## 0. 一句话

**在郑卿梦里的御膳房，周全只能看见面朝方向的一扇光；他贴着墙、等巡逻转身、从背后一刀把人化成光，再变成对方的模样，跟着老麦走出传膳门。**

## 1. 体验与循环合同

### 1.1 玩家身份与承诺

- 玩家是**周全**：一个没有战斗力的高中生，手里只有一把没有柄的白光匕首「解」。
- 承诺：**这不是砍杀游戏，是“看准了再动”的潜入**。正面被发现很危险，背后一刀很安静；每一次移动都是在选“现在走还是再等半秒”。
- 目标感受：**屏住呼吸的紧张 + 得手后的坏笑 + 厨房荒诞的喜剧**。不做恐怖、不做血腥、不做苦大仇深。

### 1.2 experienceProfile

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 节奏 | 慢观察 / 短爆发 | 大部分时间在等巡逻、找缝隙；得手只有 0.35 秒 |
| 压力来源 | 被看见 | 不是 HP，是“暴露”；被抓 = 被踢出梦域 |
| 失败代价 | 低 | 从最近检查点重来，10–30 秒 |
| 喜剧密度 | 中高 | 灶台彩蛋、小白吐槽、老麦老肯的废话 |
| 操作复杂度 | 低 | 摇杆 + 交互 + 偷袭 + 潜行，四个动词 |
| 单节时长 | 8–12 分钟 | 第一幕 4–5 分钟，第二至五幕 4–6 分钟 |

### 1.3 核心循环

```text
观察（视锥/巡逻/掩体）
  → 选路线（等转身 / 贴墙 / 绕案台 / 进掩体）
  → 移动（走 / 潜行 / 跑）
  → 接敌选择（绕开 / 背后偷袭 / 躲藏）
  → 世界回应（敌人消散 / 警戒上升 / 被发现）
  → 剧情推进（门开 / 老麦出现 / 变身）
  → 下一段更难的观察
```

### 1.4 主要玩法先例

- **《盟军敢死队》《影子战术》**：可见视锥 + 巡逻节奏 + 背后处理；本作把它压成竖屏单摇杆。
- **《阴暗森林》**：视野外压黑，只保留记忆地形；本作只两态：**探索过=正常色（不显示敌人）**，**未探索=黑**；敌人进出视野 180ms 淡入淡出。
- **《杀手》**：伪装让 NPC 不认人；本作把“善变”做成脚本化的跟随段，不做到处换装。
- **原著第 3 章**：御膳房、疯狂星期四、干草堆、老麦老肯、“看，飞机！”、变成老麦——这是本节的骨架。

### 1.5 原著给了什么，改编改了什么

| 项 | 原著 | 本作 | 理由 |
| --- | --- | --- | --- |
| 进入方式 | 选「时空锚点」、看地图、三次限制 | 小白直接送回御膳房；删掉锚点/选点/读档说法 | 用户 2026-10-31 明确要求删除 |
| 地图 | 文字描述“几十口灶眼” | 32×64 连续可走地图 | 玩家探索一整张地图 |
| 敌人 | 老麦、老肯两个幻影 | 3 条巡逻 + 1 个教学目标 + 1 个矿工门卫 | 需要可玩的潜行沙盒；原创补充登记 §8.3 |
| 背刺 | 文字一笔带过 | 玩家操作：背后 120°、1.2 格、按「偷袭」 | 把原著的“解”做成核心动词 |
| 善变 | 规则说明 + 变成老肯/老麦 | 第一次偷袭后脚本化变身 + 跟随段 | 保留名场面，不做完整换装系统 |
| 失败 | 被踢出梦域 | 失败卡 + 最近检查点重开 | 无锚点说法；短惩罚 |
| 喜剧 | 约四成吐槽 | 保留灶台彩蛋、小白概率、老麦废话 | 原著基调 |

### 1.6 体验取舍（“游戏体验为上”的具体含义）

1. **一张图而不是八个小房间**：连续潜行更有“摸进一座宫殿”的感觉；代价是相机/迷雾/寻路，靠区域标题+目标箭头+记忆迷雾兜底。
2. **视野受限而不是全图可见**：受限才有“绕背”的决策；代价是手机屏幕容易黑，靠 1.5 格环境光 + 35% 记忆层 + 常显视锥兜底。
3. **偷袭秒杀而不是进战斗**：当前没有完整回合制，且“一刀无声”才是「解」的幻想；代价是没有数值成长，靠路线选择和风险承担提供深度。
4. **善变脚本化而不是完整系统**：这一节要的是“变成老肯骗过老麦”的名场面，不是换装沙盒；代价是重玩价值低，靠路线/巡逻处理方式补一点。
5. **不做小地图**：小地图会把巡逻变成雷达，毁掉“观察”的核心；代价是可能迷路，靠分区标题、地标、目标箭头。
6. **失败不惩罚**：没有锚点/存档说法，但内部检查点很密；玩家可以大胆试。

## 2. 世界规则与信息边界

### 2.1 梦域规则（只写运行时用得到的）

| 规则 | 表现 | 玩法后果 |
| --- | --- | --- |
| 梦域是梦主欲望的投射 | 御膳房煮的是炸鸡、汉堡、可乐 | 灶台彩蛋；环境荒诞 |
| 梦域幻影 | 老麦、老肯、御厨、太监都是郑卿梦里的投射 | 可以被「解」解离；消散成光，不流血 |
| 矿工 | 因泰里的信息态机器人，伪装成梦中人 | 门卫；红色视锥；「善变」也骗得过 |
| 解 | 无柄白光匕首，刺碎核心 | 背后偷袭 = 无声解离 |
| 善变 | 用「解」命中后变成目标，读取部分记忆，十分钟 | 第一次偷袭老肯后自动变身；巡逻/门卫不认 |
| 被发现 | 梦域把外来者强制踢出 | 失败卡；小白再送进去 |
| 梦主不在这 | 郑卿在养心殿，御膳房只有幻影 | 玩家可以放开手脚，不用怕伤到老郑 |

### 2.2 删掉「锚点」之后，入口/失败/重开怎么说

- **入口**：小白说「同一段梦会重演。上次你在金殿留下的痕迹已经被抹平了，但他记住了‘有刺客’。这次换个地方——御膳房，他平时不会去。」不出现高维、胶片、时空裂缝、选点地图、三次限制。
- **失败**：小白说「你被梦域吐出来了。我可以再送你进去。」不出现存档/读档/复活点。
- **重开**：界面只说「再进去」；进度系统内部叫检查点，对白不解释。
- **禁用词**见 §6.2；未来加内容测试，只扫 `src/story/**` 与 `src/ui/**` 的游戏面向字符串，不扫小说原文和历史文档。

### 2.3 信息边界（谁知道什么）

| 事实 | 世界 | 玩家 | 人物 |
| --- | --- | --- | --- |
| 老麦/老肯是幻影 | 是 | 小白说「附近有梦域幻影」 | 老麦/老肯自己不知道 |
| 门卫是矿工 | 是 | 看到红色视锥 + 小白警告 | 老麦/老肯以为它是禁军 |
| 传膳门从外面闩着 | 是 | 交互后知道 | 老麦有钥匙/门闩 |
| 善变十分钟 | 是 | 小白说明；HUD 有 10:00 徽章 | 老麦只认脸，不认时间 |
| 老肯已被替换 | 是 | 玩家亲手做的 | 老麦最后才发现 |
| 巡逻路线 | 固定 | 只能靠观察，不给雷达 | 幻影按路径走 |

- 不做隐藏惩罚：敌人看见你之前，视锥、`?`、`!`、音效都会给信号。
- 小白能读周全的思维（原著设定），所以她的吐槽可以当“内心 OS”，但不能替玩家做选择。

### 3.1 第一幕 · 落点与探索（柴房→灶房→备膳间→库房→传膳廊）

**目标**：摸清御膳房，找到通往前殿的路。

| 节拍 | 触发 | 发生什么 | 玩家要做什么 |
| --- | --- | --- | --- |
| 落点 | 场景开始 | 白光散；柴房；小白说明（无锚点）；授「解」；移动/视野教学 | 推方向，看视锥转；走到灶房 |
| 灶房初见 | 进入灶房 | 一个御厨背对走道看锅；视锥朝西；小白提示「背后可以偷袭」 | 绕背按「偷袭」，或绕开 |
| 灶台彩蛋 | 靠近 5 个灶台 | 掀锅：吮指原味鸡、黄金脆皮鸡、劲爆鸡米花、新奥尔良烤翅、鳕鱼堡、脆皮甜筒、可乐；小白吐槽 | 可选交互；不强制 |
| 库房 | 从备膳间侧门进 | 货架、坛子、疯狂星期四纸箱；小白解释“梦主欲望投射” | 可选探索；无敌人 |
| 巡逻 | 灶房/备膳间 | 西、东、备膳间三条巡逻；视锥常显 | 等转身、贴墙、绕案台；可偷袭可绕开 |
| 门 | 走到传膳门触发点 | 门从外面闩着；小白「等有人来开」；目标变「门从外面闩着」 | 听完对话；第二幕自动开始 |

**第一幕的决策**：
- 走哪条路：中央走道最快但正对巡逻；西/东侧道更安全但绕远。
- 打不打：偷袭能永久减少一个巡逻，但要靠近、要等背；绕开更稳但后面跟随段更挤。
- 进不进库房：纯彩蛋，不给数值奖励；给的是“这个世界是郑卿的梦”的信息。

### 3.2 第二幕 · 门开（传膳廊/备膳间）

**目标**：躲起来。

| 节拍 | 触发 | 发生什么 | 玩家要做什么 |
| --- | --- | --- | --- |
| 门开 | 玩家在门触发点听完小白 | 门闩响、门缝透光；矿工门卫先从门外进来，站到 (17,8) 面朝南；老麦老肯跟着进来（(15,4)/(16,4)，走道上，**不在墙里**） | 立刻往东跑到屏风 (18,6) |
| 指路 | 门开的同一帧 | 屏风周围 2 格先照亮（否则目标写着「躲起来」，眼前一片黑）；屏风上方钉一条 `[E] 躲到屏风后` | 朝提示跑 |
| 躲藏窗口 | 门开瞬间 | **9 秒**倒计时（HUD 不显示数字，用门轴声/心跳加速） | 按「躲在屏风后」 |
| 没躲 | 窗口结束，玩家仍在走道 | 「门卫的红光扫到了你。」→ 失败卡 | 从 `gate` 重来 |
| 躲好 | 玩家进屏风 | 屏风缝里看两人走过；矿工门卫的红色视锥扫过走道 | 等门卫转头，再跟出去 |

**为什么是 9 秒而不是 4 秒**（2026-10-31 实测改）：屏风在挡路柱 `(17,5)-(17,6)` 的东侧，
从门触发点过去要「上到 row 4 → 东移 → 下到 (18,6)」，直线 3 格实际走 7 格；
门一开玩家还要同时认出两个进来的幻影和红视锥门卫。4 秒里连方向都定不下来，
6.5 秒仍会在最后一段撞线。催命感继续由门轴声、心跳和红色视锥提供，不再靠掐秒。

**第二幕的决策**：
- 屏风在门卫北侧；玩家要绕到屏风背面（东侧），再判断“先跑还是等门卫转”。
- 屏风可探头：玩家视野变宽，但人还在掩体里，敌人判定不变；探头只影响“玩家自己能看多远”。

### 3.3 第三幕 · 灶房（老肯搜草堆）

**目标**：赶在老肯之前躲进干草堆。

| 节拍 | 触发 | 发生什么 | 玩家要做什么 |
| --- | --- | --- | --- |
| 南行 | 两人走过备膳间 | 老麦一路废话；玩家跟在后面 1.5–3.5 格；巡逻在侧道。**老麦走一段就停住等玩家**，距离 >4.5 格时头顶挂「跟上来」 | 跟住、借案台/墙、别进视锥 |
| 停灶台 | 老麦到 (15,40) | 老麦掀锅：「这锅有人动过吧？」；老肯：「怕是哪个太监偷吃」 | 从侧道绕到干草堆 (5,45) |
| 搜草堆 | 老麦：「可我看这草也被人动过……」 | 草堆周围 3 格先照亮；老肯犹豫 1.6 秒再以 82px/s 走向干草堆 (6,45)（玩家步行 140）；小白：「干草堆被发现概率 52.10%；橱柜 15.68%」 | 提前进干草堆；**不要躲橱柜** |
| 偷袭窗口 | 老肯探头进草堆 | 敌人头顶出现匕首图标；「偷袭」按钮亮 | 按「偷袭」 |
| 得手 | 偷袭成功 | 白光斜斩；老肯化成光点；善变激活；玩家外观变老肯；老麦回头：「老肯？你蹲那儿干嘛？」 | 站起来，跟老麦走 |
| 没赶上 | 老肯到草堆时玩家不在里面且在视野内 | 「谁在那儿？」→ 失败卡 | 从 `gate` 重来 |
| 躲橱柜 | 玩家在橱柜里 | 老肯搜空草堆；老麦：「柜子也看看。」→ 发现 → 失败卡 | 从 `gate` 重来；橱柜只用于躲巡逻 |

**第三幕的决策**：
- **干草堆是唯一有效躲藏**：橱柜更隐蔽，但老麦会补一句「柜子也看看」；这一幕不要进柜子。
- **打不打巡逻**：西侧巡逻 `(7,44)` 紧贴干草堆；不打就要卡它的转身窗口，打就要先绕背。
- **走哪条侧道**：西侧近但 P1 巡逻密；东侧远、有案台遮挡，但横穿到草堆会经过 P2 的视线。

### 3.4 第四幕 · 跟随（备膳间→传膳廊）

**目标**：跟住老麦，别露馅。

| 节拍 | 触发 | 发生什么 | 玩家要做什么 |
| --- | --- | --- | --- |
| 起身 | 偷袭后 1 秒 | 玩家是老肯；HUD 显示「老肯」+ 10:00；巡逻不再识破；「偷袭」按钮隐藏 | 跟老麦走 |
| 应答 1 | 备膳间 (15,20) | 老麦：「老肯，你说这新皇上是不是比太上皇强？」 | 2.5 秒内按「嗯」 |
| 应答 2 | 备膳间 (15,15) | 老麦：「你说咱俩这回是不是发达了？」 | 按「不错」 |
| 应答 3 | 传膳廊 (15,10) | 老麦：「楚公公催这么急，是不是又要赏咱？」 | 按「对头」 |
| 门卫 | 传膳廊 (17,8) | 矿工门卫红色视锥扫过来；它盯着“老肯”看了 2 秒，转回去 | 不要跑、不要贴脸、不要攻击 |
| 疑心 | 全程 | 距离 >4.5 格 2 秒 / 2 格内跑 / 应答错过 → 疑心 +1；3 点满 → 老麦提前转身「你变了」 | 保持 1.5–3.5 格；走，不跑 |

**第四幕的决策**：
- **跟多紧**：太近会踩鞋/被疑心；太远会跟丢/被巡逻看见（虽然巡逻不认你，但门卫会）。
- **疑心从第一次靠近老麦 4 格内才开始计**：偷袭后从草堆走回他身边那段不计，避免“刚得手就被扣分”。
- **接不接话**：不接只是疑心 +1，不会立刻失败；三次全不接就提前进第五幕。
- **跑不跑**：跑能追上，但会惊动老麦；这一段是“走”的段落，不是“跑”的段落。

### 3.5 第五幕 · 收尾（传膳门）

**目标**：看，飞机！

| 节拍 | 触发 | 发生什么 | 玩家要做什么 |
| --- | --- | --- | --- |
| 停步 | 老麦到 (15,5) | 老麦停住，回头冷冷看「老肯」：「老肯，你变了。」 | 听 |
| 辩解 | 对话 | 老麦：「你以前从来不这么敷衍我……想当初咱俩穿一条开裆裤的时候……」 | 点继续 |
| 出招 | 对话选项 | 周全内心：「不如试试？」；屏幕出现「看，飞机！」大按钮 | 5 秒内按 |
| 得手 | 按下 | 老麦转头看天；白光斜斩；老麦化成光；善变 → 老麦；捡起鸡块 | 走 |
| 出门 | 走向传膳门 | 矿工门卫敬礼；门缝白光；白闪；结束卡 | 看结束卡 |
| 错过 | 5 秒不按 | 老麦：「你手抖什么？」再给一次；再错过 → 失败卡 | 从 `follow` 重来 |

**第五幕的决策**：
- 只有一个按键，但前面所有观察/等待/跟随都是为了这 5 秒；按下的手感要重（慢动作、音效、白闪）。
- 失败只回到 `follow`，不重打草堆。

### 3.6 橱柜：不是第三幕的备选（已决）

- 第三幕是脚本化搜场：老肯搜草堆，老麦补一句「柜子也看看」。玩家躲橱柜 → 被发现 → 失败卡。
- 理由：如果允许橱柜成功，玩家没有变成老肯，后面「你变了」、门卫伪装、跟随段全部失效；要么加一条大分支，要么出逻辑漏洞。本节砍掉分支。
- 橱柜仍是**普通掩体**：躲巡逻、第二幕临时藏身可用；只是这一幕不保命。
- 小白在失败重开时补一句：「概率模型未计入老麦的疑心病。」保留 52.10% / 15.68% 的吐槽。

### 3.7 决策权与因果

- 玩家拥有**路线权**：走哪条道、打不打巡逻、躲哪个掩体、跟多紧。
- 玩家拥有**时机权**：等巡逻转身、等门卫扫过、等老肯探头。
- 玩家不拥有**剧情权**：老麦/老肯的台词、门什么时候开、最后必须变成老麦走出门，都是固定的。
- 世界回读：打掉的巡逻不会复活；躲过的巡逻还在；玩家在草堆/橱柜的选择改变结果是“得手/被发现”；疑心值改变老麦什么时候转身。
- 没有“多结局”：只有“顺利得手 / 被发现重来”；橱柜在第三幕是陷阱，不是分支。

### 4.2 视野/迷雾的可读性

- 当前可见：地图 100%，敌人/视锥/交互物全显示；视锥边缘有一圈暖白渐隐，不能是硬边。
- 敌人身体只在身体位置进入当前可见层时绘制；敌人视锥与可见区域有交集就绘制（可只看到一截锥尖）——先看到危险，再看到人。
- 已探索：地图保持正常颜色，不显示敌人、视锥、交互物；让玩家记得“那边有门”，但不知道“现在有没有人”。
- 未探索：纯黑；不保留墙线。
- 敌人/老麦老肯：进入玩家视线 180ms 淡入，离开视线 180ms 淡出；探索过但当前不可见的区域只显示地图，不显示角色。
- 玩家脚下 1.5 格环境光：永远看得见自己，不会“走进黑洞”。
- 被敌人盯上时：屏幕四边出现极淡的红/黄呼吸，不遮挡画面；即使敌人在视野外，也给“被注视”的信号。
- 降低动效：关闭视锥呼吸、屏幕红边改成静态细框；迷雾层不闪。

### 4.4 失败与重开

| 失败 | 触发 | 失败卡文案 | 重开点 |
| --- | --- | --- | --- |
| 被发现抓住 | 追击中距离 <40 持续 0.3s | 「被发现了」「梦域把你吐了出去。」 | 最近检查点 |
| 第二幕没躲 | 躲藏窗口（9 秒）结束后仍在走道 | 「被发现了」「门卫的红光扫到了你。」 | `gate` |
| 第三幕没赶上 | 老肯到草堆时玩家在视野内 | 「被发现了」「老肯看见了你。」 | `gate` |
| 第三幕躲橱柜 | 老肯搜空后老麦要求开柜 | 「被发现了」「柜子里藏不住。」 | `gate` |

- 失败卡按钮：「再进去」（主）/「返回标题」（次）；不出现「读档」「锚点」「复活」。

- 重开时：敌人回巡逻起点、警戒清零、玩家回检查点、剧情旗标恢复到该检查点；巡逻相位用 `seed` 重算，保证同一 seed 同一开局。
- 预览模式：失败卡可用，「再进去」重开同一舞台；不写 `avm.progress.v1`。

### 4.5 镜头与画面安全

- 相机跟随，不手动旋转；地图边缘夹住，不露黑边。
- 对话/过场时相机停在玩家附近，不切走；HUD 仍在屏幕层。
- 屏幕层特效（视锥/迷雾/红边/字卡）不随相机缩放；世界层（角色/地图/敌人）随相机。
- 原生 UI（摇杆/提示/警戒眼/章节卡/遮幅）一律 `scrollFactor(0)`；输入命中统一用屏幕设计坐标（`pointer.x / plan.scale`），世界对象才用 `getWorldPoint`。相机滚动后沿用 `pointer.worldX` 会让摇杆和「点屏幕推进对话」错位。
- `prefers-reduced-motion`：关震屏、关慢动作、关视锥呼吸、关屏幕红边呼吸；保留信息层。
- 隐藏时不做相机 zoom（会把 Compose 对话框一起放大，见 AGENTS 硬规则 15）；用屏幕暗角/遮幅表达。

### 8.2 通过标准

- `pnpm check` 全绿（typecheck + vitest + assets:check + assets:pass）。
- 390×844 与 1200×648 各走一遍；控制台 0 error / 0 warning。
- 视锥、迷雾、巡逻、偷袭、躲藏、失败/重开全部可复现；同一 seed 同一开局。
- 预览模式不写 `avm.progress.v1`；`?hud=0` 截图无遮挡。
- 帧率：中端机 60fps，低端机不低于 30fps；迷雾重算 ≤4ms/帧（10Hz 下）。

### 8.3 验证不通过就改设计，不改文案

- 如果“看不见”导致挫败：先调视野/记忆/音效，不靠加旁白解释。
- 如果“等巡逻”变成发呆：缩短路径、加掩体、加可交互的噪音诱饵（拍手/扔鸡块）。
- 如果“偷袭”变成唯一解：给绕开路线更多掩体/更短路径，让“不打”也有收益（省时间/更安全）。
- 如果“跟随”变成走路模拟：加应答、加门卫、加巡逻交叉，让玩家手上有事做。

### 10.6 渲染层级（大图必须先改）

- 现有 `characterDepth = LAYERS.characters + feetY` 是按“房间高 ≤1600”写的；御膳房高 4096，角色 depth 会冲到 5000+，盖过 `effects` 3000 / `cinematic` 4000 / `cg` 5000，迷雾会把角色画在下面、UI 会被角色穿透。
