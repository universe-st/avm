# 剧情圣经（简版）

> 来源：用户提供的原创小说《刺客与矿工》（61.5 万字，7 卷，139 章 + 6 篇间章，未完结，断在第 139 章）。本文是改编用的提炼，不是原文替代；写剧情/对白前必须回原文核对。

## 1. 一句话

外星文明「因泰里」把人类梦境当矿场，派「矿工」伪装成梦中人开采意识能量；高中生周全被灵能族单元「小白」征召，进入梦域「解离」矿工与梦主，后来组建「群英刺客团」。

## 4. 主要人物

- **周全**：高二学生，嘴碎心软、临事冷静。能力「解」+「善变」，刺客团队长。
- **郑卿**：室友，憨直、怕爹、重义气。「帝王霸气」群体震慑。
- **乌梅**：转校生，寡言冷面，长剑/侠影；曾被校园霸凌，第三卷梦主。
- **小白 / TEAR-27**：灵能族能量单元，娃娃脸光团，机械播报腔，逐渐长出情绪。
- **苏皎月**：高个女生，共情力过强，第四卷梦主；「天籁回音」。
- **沈衡 / 沈无常**：被开除的学者，幕后第三方，能自由进出梦域。
- **晋渊 / EXCEPT-1**：另一路「刺客」，持「灭」，与周全互为镜像。
- **因泰里 / 灵能族**：一个开采，一个征召；都不是纯粹的盟友。

## 5. 改编原则

1. **一卷一章**：每卷拆 3–5 个章节包（现实调查 → 潜入 → 探索/伪装 → Boss → 现实余波）。
2. **保留喜剧**：原文约四成是吐槽与荒诞；不要改成纯苦大仇深。
3. **梦域=类型片**：每卷换题材与主色，这是美术与关卡差异化的来源。
4. **现实线不能砍**：校园、家庭、舆论、学术/体制是「为什么救人」的支点。
5. **战斗有代价**：解离不是杀戮；「灭」会真的杀死梦主（第 133 章），这条线要保留。
6. **第一季收束点**：第 138 章「梦星」——钱通死、少年散、铜钱里长出麦穗；第 139 章「对照」留作第二季第 0 集。

### 8.1 开幕旁白（用户提供，2026-10-24）

> 那天，当它成为一场席卷地球的灾难，
