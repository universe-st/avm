- 四张床二二并列：左列 col 3–11、右列 col 21–29，上下两排 row 11–25 / 35–49，**图与碰撞格逐格对齐**。
- 中间列 12–20 是一条纵向通道；**两排床之间还横着 9 行空地（26–34），整行可走**——这是玩家绕床、去床边叫醒郑卿的主要活动区。
- 量法：按 32px 切格，统计每行的蓝白像素占比（床）与橙色占比（书桌），行号一目了然。**改图后必须重新量，别沿用旧行号**（2026-10-29 就是旧行号整体偏了 6 行，床的碰撞体压住空地，玩家过不去）。
- **床的碰撞要按木框量，不是按被子**：被子从 row 35 起，但床头的棕色横杆从 row 33.9 就开始了。只按蓝白色块量会让脚踩进床头横杆（实机截图里看得一清二楚）。上排床同理，只是它上方是墙带（rows 0–10 全不可走），掩盖了这个问题。
- 过场动画里的寝室：窗在郑卿那侧、书桌紧挨着——地图上改为窗在书桌正上方、郑卿床在右侧，俯视视角下这是同一组关系。

## 7. 脚盒与视觉间余（2026-10-29）

碰撞以**脚**为准，不拿整个立绘算：

| 项 | 值 | 位置 |
| --- | --- | --- |
| 脚盒 | 56 × 18 设计 px | `src/map/player-foot.ts` |
| 视觉间余 | `padding: 8` | 同上 |
| 立绘锚点 | `origin(0.5, 0.985)`（脚在帧内 394/400） | `src/actors/player-actor.ts` |
| 判定点 | 左上、右上、左下、右下、下中 五个探针，各自外扩 padding | `src/map/core/room.ts` |

两条都是被实机反馈逼出来的：

1. **锚点 1.0 → 0.985**：立绘图帧高 400、脚的像素底在 394（下面留了 6px 鞋影）。用 1.0 当锚点时 `feetY` 比视觉脚底低 6px，角色看起来会「踩进」地面障碍。
2. **padding 4 → 8**：探针正好压在障碍格边界时，角色能贴到床沿站，手机上看着就是「脚踩在床框上」。4px 只相当于 2 个 CSS 像素，仍然像踩上去；8px 才留出看得见的缝。

副作用检查：过道/门洞/横缝都能过（最窄的门洞 6 格 = 131px，脚盒加 padding 后 72px），126 个单测 + 碰撞校验全绿。
