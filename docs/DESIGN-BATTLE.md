# 战斗系统设计（回合制）

> 状态：M1a 已实现 1v1 剧情战子集（攻击/防御、HP、固定 1 伤害、3 回合必败）；完整回合制（技能/EP/背刺/核心/队伍/Boss）仍后置。本文其余部分仍是后续目标。
>
> 关联文档：[地图系统](DESIGN-MAP.md)、[剧情圣经](STORY-BIBLE.md)、[美术风格](ART-STYLE.md)、[舞台预览](STAGE-PREVIEW.md)、[资源规范](RESOURCE-SPEC.md)。

## 0. 核心决策速览

- **中排 1–3 个敌人，玩家站左排/右排各 2 人**；位置只有左右，没有格子距离。
- **每回合 1 次行动 + 1 次免费换位**；按 SPD 排行动顺序。
- **背刺 ×1.5、夹击 ×1.1**；敌人在自己回合开始时转向最近的攻击者。
- **核心 30% 暴露**，`解` 可处决；Boss 核心阶段不重组。
- **独立战斗场景**，地图背袭 → 我方先制 + 自动背刺。
- 4 人小队、3–5 回合一场；伤害/暴击/AI 全部 seed 可复现。

## 1. 设计目标

### 1.1 一句话

**竖屏、回合制、三排站位**：敌人站在中间一排，我方角色站左排或右排；从敌人背后打有伤害加成，部分技能会强行改变角色位置。

### 1.2 体验支柱

| 支柱 | 含义 | 落到系统 |
| --- | --- | --- |
| 站位即策略 | 不是站桩比数值，而是“这一下从哪边打” | 左/右排、敌人朝向、背刺 ×1.5、夹击 |
| 读招再决策 | 敌人意图可见，换位有代价 | 行动顺序条、意图图标、免费换位每回合 1 次 |
| 破核收尾 | 矿工不是血条，是“外壳 + 核心” | 30% 核心暴露、解处决、Boss 核心阶段 |
| 快而清楚 | 手机竖屏，单场 1–3 分钟 | 4 人小队、3 敌人、伤害预览、可跳过动画 |
| 有代价 | 解离不是无脑杀戮 | 核心重组、自爆、Boss 心防、撤退无奖励 |

### 1.3 不做

- 不做战棋格子/移动力/地形高低差；位置只有“左排/右排/中排”。
- 不做实时/半即时 ATB；不做 QTE。
- 不做抽卡、装备词条、无限刷装；M1 只做固定队伍与线性成长。
- 不做自动战斗（可作为后续无障碍选项，但不在首版）。

## 2. 战场结构

### 2.1 三个阵区

竖屏下战场分为三个**阵区**：左排、中排、右排。中排是敌人所在的**横排**，左排/右排是玩家可站的两条边排：

```
        左排            中排（敌）           右排
      ┌──────┐        ┌──────────┐       ┌──────┐
      │ L0   │        │  M0 M1 M2 │       │ R0   │
      │      │        │  敌人横排  │       │      │
      │ L1   │        │          │       │ R1   │
      └──────┘        └──────────┘       └──────┘
```

- **中排**：敌人所在的一排，横向 3 个位置（M0/M1/M2），1–3 个敌人。
- **左排 / 右排**：玩家可站的两条边排，每排 2 个位置（L0/L1、R0/R1）。
- 队伍上限 4 人，默认 2/2 分布；少人时留空位。
- 位置**没有距离概念**：近战可以打到任意敌人，差别只在“从哪一侧打”和“敌人面朝哪边”。
- 同排前后位（L0/L1）只影响显示与同分目标优先级，不改变伤害；真正的机制轴是“左/右”。

### 2.2 为什么这样切

- 竖屏横向只有 720，三排刚好：左 200 + 中 320 + 右 200。
- 敌人横排能一次看清 3 个目标和朝向；玩家分列两侧，天然形成“夹击/背刺”的读图。
- “背后”只需要一个二进制朝向（面朝左/面朝右），不用做 8 方向，手机上可读性最好。

### 2.3 画面坐标（720×1280 基准）

| 区域 | y | 内容 |
| --- | --- | --- |
| 顶部 HUD | 0–110 | 回合数、行动顺序条、暂停 |
| Boss 血条 | 110–150 | 仅 Boss 战显示 |
| 战场 | 160–840 | 背景、三排、角色、伤害数字 |
| 当前角色卡 | 860–960 | 头像、HP/EP、状态 |
| 指令区 | 970–1110 | 2×3 大按钮 |
| 目标/预览 | 1120–1200 | 目标名、背刺/夹击标签、预计伤害 |
| 战斗日志 | 1200–1260 | 最近 1–3 条 |

- 设计高 1280–1600：顶部 HUD 与底部指令区贴边，战场区拉伸；不做重排。表中底部区域以 1280 为基准，实际用 `H−420`（角色卡）、`H−310`（指令）、`H−160`（预览）、`H−70`（日志）贴底，战场到 `H−440`。
- 敌人位置：普通 3 敌 x=240/360/480，y=580；2 敌 x=270/450；1 敌 x=360。
- 玩家位置：左排 x=96（y=440/720），右排 x=624（y=440/720）。
- Boss：x=360，y=560，宽 192；召唤物放 (200, 720)/(520, 720)，与边排错开。
- 镜头固定，不跟随、不缩放；只有必杀/核心破碎时 120ms 轻推镜，`prefers-reduced-motion` 时取消。
- 战斗是独立舞台，不套用地图的正交俯视：地面分三条台面，中排略后缩形成纵深；不做等距菱形网格。

### 2.4 站位容量

- 左排 2 人、右排 2 人；第 5 人不进战场（M1 队伍上限 4）。
- 换位时目标排必须有空位，或与同排/异排友方交换（见 §4.4）。
- Boss 召唤物占中排空位；中排满 3 时不再召唤，避免挤爆。

## 3. 回合与行动

### 3.1 回合结构

```
战斗开始（接敌结算 / 初始朝向）
  → 第 N 回合开始：状态结算、Boss 心防触发
  → 按行动顺序逐个单位行动
       ├ 玩家：自己回合开始回 6 EP → 选指令 → 选目标 → 结算 → 动画
       └ 敌方：意图 → 转向 → 行动 → 动画
  → 回合结束：持续伤害、冷却、核心计时
  → 胜负检查
  → 下一回合
```

- 一“回合”= 所有存活单位各行动一次。
- 行动顺序在**回合开始时**按当前 SPD 从高到低排定；同 SPD 的稳定随机键整场不变。速度 buff/减速在下个回合开始时生效，不在回合中途插队。
- 显示未来 6–8 个行动头像；当前行动者鎏金描边，敌方朱红。

### 3.2 行动经济

每个角色每回合拥有：

| 资源 | 数量 | 说明 |
| --- | --- | --- |
| 行动 | 1 次 | 攻击 / 技能 / 防御 / 道具 / 撤退 |
| 换位 | 1 次（免费） | 移动到另一排空位，或与友方交换；可在行动前或行动后使用 |
| EP 回复 | +6 | 自己回合开始时；防御额外 +10 |

- 换位本身不结束回合；但**行动后再换位**等于本回合结束。
- 换位不触发借机攻击（手机端不做反应窗口），但会被“锁定”状态禁止。
- 行动顺序固定后，换位不会改变顺序。

### 3.3 指令

| 指令 | 消耗 | 效果 |
| --- | --- | --- |
| 攻击 | 0 EP | 100% ATK，近战，吃站位 |
| 技能 | 6–16 EP | 每个角色 3 个技能，见 §6 |
| 换位 | 免费 1 次 | 左排 ↔ 右排；不能换到已满的排，除非交换 |
| 防御 | 0 EP | 到下个自己回合前受伤 ×0.5，EP +10；可换位 |
| 道具 | 1 行动 | 共享背包 4 格；回复/解控/投掷 |
| 撤退 | 1 行动 | 第 2 回合起可用；必定成功，无奖励，回地图 |

### 3.4 敌方回合

1. 回合开始：若被嘲讽，目标锁定嘲讽者；否则按仇恨分数选目标。
2. **转向**：若未眩晕/未被固定朝向，转向“最近一次伤害来源所在的排”；若本回合无人打它，保持原朝向。
3. 行动：普攻或技能；有蓄力技能时提前一回合显示意图。
4. 结束：状态计时、核心计时。

> 关键：敌人是在**自己回合开始时**转身，不是被击中立刻转身。所以从背后打的那一下一定吃背刺；打完它转过来，下回合要再想办法绕背。

### 3.5 动画与节奏

| 动作 | 时长 | 备注 |
| --- | --- | --- |
| 普攻 | 450ms | 突进 + 命中停顿 60ms |
| 技能 | 600–900ms | 可跳过；AOE 逐个结算但共用一次镜头 |
| 敌方行动 | ≤ 1.2s | 意图 → 动作 → 数字 |
| 伤害数字 | 600ms | 上浮淡出；背刺加金色描边 |
| 回合切换 | 300ms | 顺序条高亮移动 |

- 任意点击可“加速播放”，不是跳过结算；结算结果早已由纯逻辑算完。
- `prefers-reduced-motion` 关闭震屏、慢动作、推镜，只保留淡入淡出与数字。

## 4. 站位、朝向、背刺与夹击

### 4.1 基础定义

| 概念 | 定义 |
| --- | --- |
| 排 | `left` / `right` / `center` |
| 朝向 | 敌人 `facing` 只能是 `left` 或 `right`；玩家不设朝向，默认面向中排 |
| 背后 | 攻击者所在排 ≠ 敌人朝向 |
| 正面 | 攻击者所在排 = 敌人朝向 |
| 背刺 | 近战/带 `positional` 标签的技能，从背后命中 |
| 夹击 | 本回合内，目标已经被**另一排**的我方单位命中过 |

> “背后”是**阵位语义**：敌人面朝左排时，右排就是背后；不要求角色真的绕到 sprite 后面。表现上用朝向箭头、脚下扇区和背刺特效表达，和地图上的 120° 背后判定是两套判定（地图看角度，战斗看排）。

### 4.2 背刺加成

| 项 | 正面 | 背后 |
| --- | --- | --- |
| 伤害 | ×1.0 | **×1.5** |
| 暴击率 | +0% | **+15%**（基础 5%，上限 50%） |
| 核心乘算 | 无 | 与核心 ×1.5 相乘（背刺 + 核心总 ×2.25） |
| 视觉 | 普通命中 | 金色斜斩 + “背刺”字 + 短暂停顿 |

- 只有 `positional: true` 的技能吃背刺；远程/音波/投掷不吃，避免“站哪都一样”和“站哪都背刺”两个极端。
- 敌人特质：
  - `backGuard`（背甲）：背刺倍率降为 ×1.2；
  - `allRound`（多目）：背刺无效，只能靠破甲/核心；
  - `fixedFacing`（石像/王座）：不会转身，背刺有效但每回合只能吃一次背刺（第二次起 ×1.0），防止站桩刷。
- 背刺只影响伤害与暴击，不影响命中（本作不做命中率，见 §5.3）。

### 4.3 夹击

- 记录每个敌人“本回合被哪些排命中过”。
- 若本次攻击的排与之前命中过的排不同 → 本次伤害 ×1.1，并显示“夹击”。
- 每回合开始清空记录；同一排连续打不触发。
- 夹击与背刺可叠乘：`×1.5 × 1.1`。
- 设计目的：即使敌人转身，另一个排的队友仍能接上夹击，鼓励左右交替而不是全员挤一侧。

### 4.4 换位与位置技能

| 来源 | 效果 | 代价/限制 |
| --- | --- | --- |
| 换位（通用） | 自己到另一排空位；或与任意友方交换排 | 每回合 1 次；`锁定` 时不可 |
| 影步（周全） | 移动到目标敌人的背后排 | 10 EP；下一次攻击 +25%（可保留到下回合）；冷却 2 回合 |
| 侠影（乌梅） | 移动到目标背后排并立即攻击 120% | 10 EP；按背后结算（`allRound` 除外）；目标死亡则留在该排 |
| 镇岳（郑卿） | 自身与同排友方获得护盾 | 不改变位置 |
| 牵引（苏皎月，M2） | 把一名友方拉到自己所在排 | 8 EP；目标排需有空位 |
| 钻头突进（矿工·中阶） | 命中后把目标推到另一排 | 目标排已满时与友方交换；无友方可换则“锁定”1 回合 |
| 震地（Boss） | 全体我方交换左右排 | 强制交换；`锁定` 的单位留在原排 |
| 王权（Boss 心防） | 每 2 回合强制全体换排 | 与震地区分：王权是规则，不占行动 |

- 强制位移后，若目标排已满：优先与目标排的友方交换；若无法交换（被锁定/免疫），目标留在原排并获得“锁定 1 回合”。
- 位置变化会即时更新背刺/夹击判定；伤害预览在确认前刷新。
- UI 必须在技能描述里写清“位移”标签，避免玩家不知道为什么队伍换了边。

### 4.5 一个回合的例子

```
敌方 A 面朝左（facing=left），我方乌梅在左排、周全在右排。
乌梅在左排攻击 A → 正面，22 伤害。
周全在右排（A 的背后）→ 攻击 → 背刺 38 伤害；本回合 A 已被左排打过 → 夹击 ×1.1 → 43。
A 的回合：最近伤害来源是右排 → 转身朝右 → 攻击周全。
下回合：乌梅仍在左排，现在成了 A 的背后 → 乌梅可背刺。
```

## 5. 数值与伤害

### 5.1 基础属性

| 属性 | 含义 | 范围（Lv1） |
| --- | --- | --- |
| HP | 生命 | 100–190 |
| EP | 灵能，放技能 | 28–55 |
| ATK | 攻击 | 11–23 |
| DEF | 防御，减伤 | 8–17 |
| SPD | 行动顺序 | 8–19 |

### 5.2 我方 Lv1 基准

| 角色 | HP | EP | ATK | DEF | SPD | 定位 |
| --- | --- | --- | --- | --- | --- | --- |
| 周全 | 130 | 40 | 18 | 9 | 15 | 破核 / 机动 |
| 郑卿 | 190 | 28 | 16 | 17 | 8 | 坦克 / 控场 |
| 乌梅 | 115 | 36 | 23 | 8 | 19 | 背刺 / 爆发 |
| 苏皎月 | 105 | 55 | 11 | 10 | 13 | 治疗 / 辅助 |

> 这是“满编队伍”的系统基准，不代表首章四人同时入队；乌梅、苏皎月按剧情节点加入。首章若只有 3 人，按 §14 的风险项下调敌方 HP。

### 5.3 伤害公式

```ts
const positional = skill.positional && attackerWing !== target.facing; // 背后
const pincer = target.hitFromOtherWingThisRound;
const core = target.coreExposed;

let raw = atk * skill.power;
raw *= positional ? (target.backGuard ? 1.2 : 1.5) : 1.0;
raw *= pincer ? 1.1 : 1.0;
raw *= core ? 1.5 : 1.0;
raw *= crit ? 1.5 : 1.0;

const mitigation = target.def * (core ? 0.5 : 1.0) * 0.8;
const damage = Math.max(1, Math.round(raw * rand(0.95, 1.05) - mitigation));
```

- 暴击率：基础 5%；背刺 +15%；`一剑` 额外 +20%；上限 50%。暴击用同一 seed 的 RNG，不额外掷命中。
- 伪装首击在公式外再 ×1.2（一次性）；背袭开局直接全破，不触发首击加成。
- `解` 对核心暴露的 ×2 是技能特效，在公式外乘；与背刺、核心乘算（见 §5.4）。
- 随机只影响 ±5% 伤害；不掷闪避，避免手机端“空大”挫败。
- 伤害预览显示区间（min–max）与标签（正面/背刺、夹击、核心、暴击可能），不显示精确值。
- 防御减伤是减法而非百分比：高防对多段小伤害更强，对重击较弱，便于做“坦克/脆皮”差异。

### 5.4 数值示例

目标：矿工·中阶，DEF 13，HP 130。

| 攻击 | 条件 | 计算 | 伤害 |
| --- | --- | --- | --- |
| 乌梅·一剑（140%） | 正面 | 23×1.4=32.2 − 10.4 | **22** |
| 乌梅·一剑 | 背刺 | 32.2×1.5=48.3 − 10.4 | **38** |
| 乌梅·一剑 | 背刺 + 夹击 | 48.3×1.1=53.1 − 10.4 | **43** |
| 乌梅·一剑 | 背刺 + 夹击 + 暴击 | 53.1×1.5=79.7 − 10.4 | **69** |
| 周全·解（110%） | 背后 + 核心暴露 | 18×1.1×1.5（背刺）×2（解）×1.5（核心）=89.1 − 5.2 | **84** |

> 背刺让同一招从 22 提到 38（+73%）；叠夹击 43；暴击 69。目标是“值得绕背”，但不是“不绕背就打不过”。

### 5.5 敌人 Lv1 基准

| 敌人 | HP | EP | ATK | DEF | SPD | 特质 |
| --- | --- | --- | --- | --- | --- | --- |
| 矿工·伪装 | 80 | 0 | 21 | 6 | 10 | 首击破伪装 |
| 矿工·中阶 | 130 | 20 | 27 | 13 | 12 | 钻头突进（推排） |
| 矿工·精英 | 300 | 40 | 34 | 19 | 13 | `backGuard`、核心脉冲 |
| Boss（卷一） | 900 | 80 | 42 | 24 | 11 | 三阶段、心防、核心 |

- 敌方对我方伤害示例：中阶 27 − 9×0.8 = 19.8 → 对周全约 20；Boss 42 − 17×0.8 = 28.4 → 对郑卿约 28。
- 一场普通战 3–5 回合；Boss 8–12 回合；首章不做过长的消耗战。

### 5.6 成长

- M1：固定 Lv1，不做升级。
- M2：每章 +1 级，HP/ATK 线性 +12%/章，DEF +8%/章，SPD 不变或微调；技能解锁跟剧情走。
- 不做随机词条；装备只做“核心/护符”少量固定件，避免数值膨胀。

### 5.7 核心与破核

每个矿工有“外壳 + 核心”两段：

| 阶段 | 触发 | 规则 |
| --- | --- | --- |
| 伪装 | 战斗开始 | 首次受击 +20% 伤害并破伪装；背袭开局直接全破 |
| 战斗 | 破伪装后 | 正常 HP 阶段 |
| 核心 | HP ≤ 30% | 核心暴露 2 回合：DEF ×0.5、受伤 ×1.5；`解` 伤害 ×2 |
| 重组 | 暴露 2 回合未击破 | 回复 25% maxHP、核心关闭（普通/精英限 1 次） |

- 核心暴露时头顶出现朱红核心图标，HUD 提示“用解破核”。
- 普通矿工在核心暴露期间被击杀 → 正常解离；未击破则重组，逼玩家留爆发。
- 精英/Boss 的核心计时单独显示；Boss 在 <30% 进入永久核心阶段，不重组（Boss 例外，见 §8.3）。
- `解` 击杀核心暴露目标：额外 +1 核心掉落；这是“刺客”身份的收益。

## 8. 敌人 AI 与 Boss

### 8.1 目标选择

```
score = 0.35 × (1 − hp/maxHp)        // 优先残血
      + roleWeight                    // 治疗 1.5，脆皮 1.2，坦克 0.8
      + facingSideBonus 0.15          // 面朝的那一排稍优先
      + tauntOverride                 // 嘲讽直接锁目标
```

- 同分用战斗 seed 的稳定随机键决定；不每帧重掷。
- 敌人可以攻击任意排（突进/远程表现），但**面朝的那一排受伤后会转身**，这是背刺循环的核心。
- 敌方不会攻击自己人；玩家 AOE 也不伤友军，降低误操作成本。

### 8.2 技能选择

1. 有嘲讽 → 对嘲讽者普攻/单体技能。
2. 有蓄力技能且冷却好 → 蓄力（头顶显示意图）。
3. 友方低血且有治疗 → 治疗。
4. 中排有 2+ 目标且 AOE 可用 → AOE。
5. 否则普攻；血量 <30% 的玩家优先。

- 每回合开始显示敌人意图图标（普攻/蓄力/AOE/召唤/治疗），玩家可据此换位。
- 敌人 EP 不够时不会空放技能；AI 决策纯函数，输入 `state + seed` 得同一结果。

### 8.3 Boss 阶段

| 阶段 | HP | 行为 | 心防 |
| --- | --- | --- | --- |
| 一·试探 | 100–60% | 普攻 + 王权；每 2 回合强制换排 | 规则卡展示 |
| 二·震怒 | 60–30% | 召唤禁卫；核心脉冲；AOE 蓄力 | 追加“聚光/剑意” |
| 三·核心 | <30% | 永久核心暴露；每回合核心崩解蓄力 | 核心计时 5 回合，未破则全队重创 |

- Boss 15 回合狂暴：全体 ATK +50%，不再召唤。
- Boss 的核心暴露不重组，但每回合对全体造成递增压力，逼玩家在 5 回合内破核。

### 8.4 心防战规则（数据驱动）

```ts
interface BattleRule {
  id: string;
  title: string;
  text: string;
  onBattleStart?(ctx: BattleRuleContext): BattleEvent[];
  onRoundStart?(ctx: BattleRuleContext): BattleEvent[];
  onDamage?(ctx: BattleRuleContext, event: DamageEvent): DamageEvent;
  onRoundEnd?(ctx: BattleRuleContext): BattleEvent[];

```

| 示例 | 规则 | 玩法后果 |
| --- | --- | --- |
| 王权·朝堂 | 每 2 回合全体强制换排；该回合背刺倍率 +0.25（×1.75） | 玩家必须重新规划背刺位 |
| 追光·剧院 | 回合开始随机一排被追光：该排攻击 +30%，受击 +20% | 诱导站位，但站错会被集火 |

## 9. 从地图到战斗

### 9.1 四档接敌

| 判定 | 战斗开局 |
| --- | --- |
| **背袭** | 我方先制 1 轮（敌人首轮跳过）；敌人初始背对我方入口排；首次命中必背刺（多目/背甲按特质结算）；伪装全破 |
| **侧袭** | 我方先制 1 轮；不自动背刺；敌人初始面向入口排 |
| **正面** | 按 SPD 正常排序；敌人面向入口排 |
| **被袭** | 敌方先制 1 轮；我方首轮不回 EP；敌人面向入口排 |

- “先制 1 轮”= 该轮只有先制方行动，后手方跳过；不是额外回合，避免滚雪球。
- 背袭必背刺只对**每个敌人的第一次命中**生效（`allRound` 除外）；之后按正常朝向计算。
- 背袭的敌人初始朝向 = 入口排的反方向；例如玩家从左排入口背袭 → 敌人面朝右。

### 9.2 入口排与站位

- 玩家从地图敌人左侧接近 → `entryWing='left'`；右侧 → `right`。
- 队伍沿用上一场战斗的排布；接敌时先保证入口排至少 1 人（优先郑卿/周全），若入口排已满 2 人，第三人自动去另一排，第四人补空位。
- 背袭时，入口排视为“敌人背后”；侧袭/正面时，入口排视为“敌人面前”。
- **正面接敌不等于全员正面**：敌人只朝入口排，若队伍分列两侧，另一排仍算背后——这是站位收益，不是 bug；想避免被夹击，敌人需要转向或使用 `allRound` 单位。
- 例：玩家在敌人背后（右）发起背袭 → `entryWing='right'`，敌人 `facing='left'` → 右排全员吃背刺。

### 9.3 转场与预取

```
地图接敌判定
  → 播 400ms 白闪/碎裂转场
  → 预取 battle.common + battle.<id>（进入接敌区时已开始）
  → 启动战斗场景，传入 EncounterRequest
  → 战斗
  → 结果面板
  → 回到地图，应用 EncounterResult（或回锚点）
```

- 战斗场景是独立场景，不复用地图相机/输入；退出必须能回标题（预览）或回地图（正式）。
- 资源只走 bundle；场景内不出现 `this.load.*`。

### 9.4 战斗结果契约

```ts
interface EncounterResult {
  outcome: 'victory' | 'escape' | 'defeat';
  rounds: number;
  party: { id: string; hp: number; ep: number }[];
  defeated: string[];
  loot: string[];
  seed: number;
  logHash: string;
}
```

| 结果 | 地图侧 |
| --- | --- |
| 胜利 | 移除敌人、标记清除、开门/掉宝、自动存档（预览不写） |
| 撤退 | 退到接敌前 2 tile；敌人保留并警觉；不自动存档 |
| 失败 | 回最后锚点；敌人重置；队伍 50% HP/EP；不消耗锚点稳定度 |

### 9.5 确定性

- `seed` 来自 `hashSeed(saveSeed, chapter, roomId, objectId, encounterCount)`，与地图共用。
- 战斗内所有随机（暴击、±5% 伤害、AI 同分）走 `mulberry32`，不用 `Math.random()`。
- 回放 = `seed + 初始配置 + 行动列表 + 版本号`；`logHash` 用于验收和 bug 复现。


### 11.2 核心类型

```ts

type Team = 'party' | 'enemy';

interface Combatant {
  id: string;
  name: string;
  team: Team;
  wing: Wing | 'center';
  slot: 0 | 1 | 2;
  facing?: Wing;                    // 仅敌人
  hp: number; maxHp: number;
  ep: number; maxEp: number;
  atk: number; def: number; spd: number;
  skills: string[];
  statuses: StatusInstance[];
  core?: { threshold: number; exposed: boolean; turnsLeft: number };
  traits?: ('backGuard' | 'allRound' | 'fixedFacing')[];
  ai?: string;
}

interface BattleState {
  seed: number;
  round: number;
  phase: 'opening' | 'player' | 'enemy' | 'victory' | 'defeat' | 'escape';
  order: string[];
  actorIndex: number;
  units: Combatant[];
  hitSidesThisRound: Record<string, Wing[]>;
  log: BattleEvent[];
  rule?: string;
}

type BattleAction =
  | { kind: 'attack'; actorId: string; targetId: string }
  | { kind: 'skill'; actorId: string; skillId: string; targetIds: string[] }
  | { kind: 'switch'; actorId: string; toWing: Wing; swapWith?: string }
  | { kind: 'guard'; actorId: string }
  | { kind: 'item'; actorId: string; itemId: string; targetId?: string }
  | { kind: 'flee'; actorId: string };
```

```ts
function createBattle(setup: BattleSetup, seed: number): BattleState;
function applyAction(state: BattleState, action: BattleAction): {
  state: BattleState;

```

### 11.3 事件

`turn-start` / `switch` / `damage` / `heal` / `status-add` / `status-expire` / `core-exposed` / `core-reassembled` / `unit-defeated` / `round-end` / `victory` / `defeat` / `escape` / `log`。

- 场景按事件队列播放动画；`applyAction` 返回时结果已确定，动画只负责表现。

## 12. 场景、资源、预览与存档

### 12.1 场景与模块

- 战斗作为 `GameModule`：`requires: ['battle.common', 'battle.<id>']`，用 `enterModule` 进入；返回地图也用 `enterModule`，由地图模块接收结果。
- 正式流程：地图接敌 → `enterModule(this, 'battle.ch01.corridor', payload)`；胜利后 `enterModule(this, 'map.ch01', result)`。
- 预览流程：`?stage=battle.ch01.tutorial&seed=7&phase=mid`，由 `launchStage()` 启动，不依赖存档。
- 先保留 `battle.sandbox` 作为契约回归入口，真实战斗新增 `battle.*` 条目。

## 13. 验收、测试与平衡

### 13.1 单测（纯逻辑，无 Phaser）

1. 伤害公式：正面/背刺/夹击/核心/暴击的边界与取整。
2. 背刺判定：`facing` 与 `wing` 的四种组合；`backGuard`、`allRound`、`fixedFacing`。
3. 夹击：同回合异排命中才触发；同排连续不触发；回合结束清空。
4. 换位：空位/交换/满员/锁定/强制位移的失败回退。
5. 行动顺序：SPD 排序、同分稳定、buff 下回合生效。
6. 敌人转向：最近伤害来源、嘲讽覆盖、眩晕不转身。
7. 核心：30% 触发、2 回合重组、解 ×2、Boss 永久核心。
8. 状态：刷新/叠加/递减、Boss 控制抵抗。
9. AI：同 seed 同决策；嘲讽强制目标；低血治疗。
10. 回放：seed + actions → 同一 `logHash`。

### 13.2 验收清单

- `?stage=battle.ch01.tutorial&seed=7&phase=opening|mid|victory|defeat|boss` 均可打开、可返回。
- 同一 seed 重开，行动顺序、伤害、AI 完全一致。
- 390×844 与 1200×648 两个视口：三排不重叠、指令区可点、控制台 0 error。
- 背刺/夹击/核心标签在预览里可见；伤害数字不与头像重叠。
- `prefers-reduced-motion`：无震屏/推镜，结算仍完整。
- 动画中点击“加速”能缩短播放；返回键在战斗中弹确认，不丢档。
- 战斗场景不写档；预览退出后回到标题。

| 指标 | 目标 |

## 14. 风险与开放问题

1. **竖屏三排可读性**：4 人 + 3 敌 + 状态图标可能挤；先用 2/2 站位与 6 个状态图标上限验证，必要时把同排两人错位 40px。
2. **免费换位是否过强**：每回合 1 次、敌人会转身、远程不吃背刺，是当前的三道闸；实测如果“人人都能永远背刺”，改成换位消耗半行动或增加“换位后本回合受伤 +15%”。
3. **敌人转身的公平性**：玩家看不到“下回合它会转哪边”会挫败；用头顶朝向箭头 + 意图图标提前表达。
4. **夹击判定是否难懂**：先在教学 2 用固定文案解释，再考虑 HUD 显示“本回合已从左/右命中”。
5. **4 人队伍 vs 3 敌**：数值按 4 人设计；如果首章只有 3 人，需要把敌方 HP 下调 15%。
6. **心防规则与背刺循环打架**：例如“不许跑”限制换位，可能让背刺职业失业；每卷至少保留一条“可利用背刺”的解法。
7. **是否要自动战斗**：首版不做；若做，只作为重复刷素材的无障碍选项，且不能用于 Boss/首通。
8. **成长与数值膨胀**：七卷线性增长容易变成“数值碾压”；优先用新技能/新心防制造差异，而不是纯加攻。
