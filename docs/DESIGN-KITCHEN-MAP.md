## 0. 一句话

**32×64 格、单张连续、无房间切换**的御膳房：南边柴房出生，中间灶房是主潜行沙盒，北边备膳间与传膳廊把玩家送到封死的传膳门；门是以后养心殿的接口。

## 1. 比例与坐标

| 项 | 值 | 说明 |
| --- | --- | --- |
| 网格 | **32 列 × 64 行** | 一张 ASCII 碰撞图，不拆房间 |
| 设计 tile | **96×96 设计单位** | 2026-10-31 由 64 放大 1.5×：角色 245px 从 3.56 格降到 **2.55 格**，一屏 11.25 格 → **7.5 格** |
| 设计尺寸 | **3072×6144** | 竖屏 720 宽约 4.3 屏宽、约 4 屏高 |
| 美术源图 | **1536×3072**（48px/格） | `public/assets/img/map/ch01/kitchen.webp`（WebP q88，约 0.7MB；PNG 要 5–6MB）；显示时整数 2× |
| 视口 | 720×1100–1600 | 可见约 **7.5 列** × 11–17 行 |
| 坐标换算 | `x = col*96 + 48`，`y = row*96 + 48` | 角色脚底用设计坐标，不直接存 tile |
| 地图原点 | `(0, 0)` | 相机 bounds = `(0,0,3072,6144)` |

- 角色脚盒用 `KITCHEN_PLAYER_FOOT`（66×24，padding 6，合计 78px < 一格 96px）；最小通道 **1 格** 就能过，正常设计仍留 ≥3 格。
  寝室那套 `PLAYER_FOOT`（56×18，padding 8，合计 72px）是按 21.8px 格子调的，在这里比一格还宽，会把玩家卡死在屏风格里——别再混用。
- 老麦/老肯的中央通道至少 **3 格**；实际中央走道 8 格，足够错身。
- 相机不再固定：`startFollow(player, true, 0.12, 0.12)`，deadzone 120×180，`setBounds` 到地图；开局 `centerOn` 出生点并夹在边界内。

## 4. 图例与通行/视线规则

| 字符 | 含义 | 可走 | 挡视线 |
| --- | --- | --- | --- |
| `#` | 墙、灶台、立柱、柜子、货架、屏风、实心门 | 否 | **是** |
| `.` | 地面 | 是 | 否 |
| `~` | 可走装饰（干草堆、地毯、水纹） | 是 | 否 |
| `o` | 矮障碍（案台、坛子、水缸、筐） | 否 | 否 |
| `P` | 出生点（有且只有一个） | 是 | 否 |
| `=` | 可走门（本图暂未使用，留给后续房间） | 是 | 否 |

- **视线遮挡只认 `#`**；`o` 挡路不挡视线，所以玩家不能把矮案台当掩护，必须找墙、柜、屏风或干草堆。
- 干草堆/橱柜/屏风是 `HideDef`，不是普通 tile；干草堆脚下是 `~`，玩家可以走进去；橱柜/屏风是 `#`，玩家站在相邻格按交互进入。
- 实心门（传膳门/后门）是 `GateDef` / `InteractableDef`：占格不可走，交互/剧情触发开门；脚本演员可以无视碰撞穿过。

| id | 类型 | 路径（col,row） | 停留 | 扫视 | 速度 | 视野 |

| `cook.tutorial` | 幻影·御厨 | 站在 **(13, 36)**，面朝西 | — | — | 静止 | 100° / 4.5 格 |

- `cook.tutorial` 是第一个背刺教学目标：背对中央走道，玩家从东侧接近；不打也能绕开。
- 巡逻路径的每一点和每条直线段都必须可走；`patrol.west` 的 `(7,44)` 紧贴干草堆，是第三幕最大的时间压力来源。
- `guard.miner` 第一幕不在场；第二幕门开时从门外进来，站到 `(17,8)`。第二幕玩家还没伪装，必须避开它的锥；第四幕玩家是老肯，它无视。

| 南行 | `(15,10) → (15,15) → (15,20) → (15,24)` | 穿过传膳廊、备膳间、中央拱门；边走边聊 |

## 6. 镜头、区域标题与寻路

- 相机：`setZoom(plan.scale)` + `startFollow` + `setBounds(0,0,2048,4096)`；deadzone 120×180；不做手动旋转。
- 开局相机 `centerOn(spawn)` 并夹在 bounds 内；地图边缘不露黑边。
- 区域标题：跨过分区边界时，左上目标条下方淡入「御膳房 · 灶房」2 秒；同一分区不重复。
- 目标箭头：目标在屏幕外时，屏幕边缘给一个小箭头 + 距离（格），不做小地图。
- 迷雾/视锥是屏幕空间层，不随相机缩放变形；详见 `DESIGN-CH01-EXPLORE.md` §3.4。
- 调试：`?stage=scene.ch01.kitchen&debug=1` 画碰撞格、巡逻路径、视锥、躲藏点、触发区。

## 7. 构建校验（下一轮实现）

1. `assets-src/map/ch01/kitchen-map/pass-grid.json`：32×64，`1` 可走；`map-final.png` 1024×2048；`map-pass.png` 检查图。
2. `tools/gen-pass-grid.py` 扩展为可指定房间（`--room ch01-kitchen`），从 `map-manifest.json` 生成 ASCII；`pnpm assets:pass` 同时校验寝室与御膳房。
3. `validateRoom` 扩展后必须通过：
   - 64 行 × 32 列；边界全 `#`；`P` 恰好一个；
   - 每个巡逻点可走，相邻点直线段可走；
   - 每个 `HideDef` 的站位格可达，且能被玩家站到；
   - 门触发、后门交互、干草堆、橱柜、屏风、库房从出生点 BFS 可达；
   - 最小通道 ≥2 格；老麦路径 ≥3 格。
4. 人工校验：`debug=1` 下从出生点走到传膳门，确认五个分区、三条巡逻、三个躲藏点、一个教学目标都在正确位置。

## 8. 美术交接（白盒不需要）

- 源图 1024×2048（32px/格），显示 2×；可以一张整图，也可以按 `map-manifest.json` 拼合。
- 需要的整图/部件：石砖地面、宫墙、6 组灶台（含锅/蒸笼/火光）、两个长案岛、长案、货架、坛子、挂肉架、干草堆、橱柜、屏风、传膳门、后门、木箱、水缸、筐。
- 动态层（不进静态图）：蒸汽、灶火、浮尘、门缝光、干草堆高光。
- 色板：厨房暖琥珀/朱红 + 北门冷月光；迷雾深棕黑；玩家视锥暖白；幻影视锥冷白，矿工视锥猩红。
- 禁止：地图里烤人物、烤文字、写实血腥；角色和 UI 一律运行时叠。
- 包体：`ch01.kitchen`（地图 + 幻影/老麦/老肯/矿工 + 厨房音频），地图 ≤6 MB，整包 ≤12 MB；若与 `ch.01` 共用周全精灵，先拆 `ch01.char` 共享包，避免重复加载寝室图。
- 登记：`docs/ASSET-CREDITS.md`（jobId/模型/后期）、`docs/RESOURCE-SPEC.md`、`src/assets/keys.ts`、`src/assets/bundles.ts`。
