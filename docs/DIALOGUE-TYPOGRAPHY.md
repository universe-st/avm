# 台词排版：翻页断点、行首禁则与不拆数字

> 需求（2026-11-21 用户原话）：
> 「当一名角色单段对话过长需要翻页时，应该在合适的地方断开。并且任何换行的地方，
> 新行第一个字符不能是除前引号、前书名号之外的任何标点符号。」

两条规则，两个实现层：

| 层 | 位置 | 负责 |
| --- | --- | --- |
| 翻页（一句切成几页） | `paginateText()` · `src/story/dialogue-player.ts` | 页与页之间的断点（寝室/御膳房/金殿共用） |
| 页内折行（一页里的换行） | `balanceDialogueLine()` · `src/story/dialogue.ts` | 孤行控制（只在尾行太短时动手） |
| 渲染层按真实字宽折行 | `rewrapOverflowingLines()` · `vendor/phaser-mvvm/packages/widgets/src/text-truncate.ts` | 真正把一行画到 676px 宽里 |

金殿过场（`PalacePlayer` + `Typewriter`）也走这一套：场景把 `say` 的整句交给
`paginateText` → `balanceDialogueLine`，再逐页喂打字机；点击顺序是「补全本页 → 翻下一页 →
推进时间线」，页码用 HUD 的 `1/3` 显示。分页参数 `DIALOGUE_PAGE_CHARS` 只有一份（`dialogue.ts`）。

## 1. 行首禁则（kinsoku）

**判定唯一源**是 `isForbiddenLineStart(char)`：

- 用 Unicode 类别 `\p{P}` 判「是不是标点」，**不维护手写标点清单**——以后剧本里出现
  `％`、`·`、`～`、英文半角标点都不会漏；
- 白名单只有**前引号 / 前书名号**：`「 『 “ ‘ 《 〈`。它们后面接的是内容，从它们起行是自然断点；
- 右引号、右括号、句号、逗号、百分号……一律不许出现在行首。

两处实现（剧情层 / 框架层）必须一致：`test/dialogue-linebreak.test.ts` 里有逐字符对拍，
框架侧另有 `vendor/phaser-mvvm/packages/widgets/test/text-truncate.test.ts` 的单测。

消除方式有两种，按「这一行还有没有余量」选：

- **翻页**用「追い込み」（往前收）：断点后紧跟的标点留在上一页，页因此最多多 1–2 个字
  （翻页后页面上限 68 + 2，仍在面板 5 行内）；
- **渲染折行**用「追い出し」（往下推）：把上一行末尾的字一起带到下一行
  （`carryDownForKinsoku()`），因为版面宽度已经用满，不能再往上一行塞字。

## 1.5 不拆数字 / 英文词

数字、英文词、百分号属于**不可拆 token**（`32.47%`、`TEAR-27`、`ETH-HB-001B`）。
断在 token 中间会把一句话读成两个意思（实测渲染层把「32.47%」切成「32.4 / 7%」）。

- 判定唯一源 `isTokenChar()`（`src/story/dialogue.ts`）：`[A-Za-z0-9%‰％._+:/#-]`，
  与框架 `text-truncate.ts` 的同名函数逐字符对拍；
- **翻页**：断点落在 token 中间时，把整个 token 留在上一页（最多多带 8 字；
  token 太长就把断点挪到它的开头，词整体进下一页）；
- **渲染折行**：把整个 token 一起带到下一行；只有 token 比一行还宽、或带下去后只剩
  一两个字时，才接受断在 token 中间（没有更好的落点）。

## 2. 翻页断点

`paginateText(text, pageChars)` 的断点优先级：

1. **句末标点**（`。！？…`）：在整页范围内找最靠后的一个，但页不能短于 45%
   ——这样每页尽量是整句，而不是「切到 68 字为止」；
2. **分句标点**（`，；、：—`）：句末标点找不到时，退到最后 8 字内最近的一个；
3. 硬切到上限。

断完之后再过一遍行首禁则；收尾页短于 6 字时，把断点往前挪到上一个标点
（挪不动、且并回上一页后 ≤ 68+8 字时直接并页，例如 70 字的句子不再出现「%。」这种 2 字页）。

页宽真值：面板内容宽 **676**、字号 34（`lg`），一行放 **19 个汉字**
（`DIALOGUE_LINE_CHARS`）；一页 68 字约 4 行。

## 3. 页内折行（`balanceDialogueLine`）

它**不再**给每页硬插一个「接近 18 字」的换行。实测那样做过：44 字旁白被插在第 23 字，
屏幕上是「19 + 5 + 19 + 1」四行，最后一行只有一个「态」。现在只做一件事：

- 按 19 字贪心折行后，若**尾行少于 5 字**（孤行），把断点前移到一个标点，让尾行多带几个字；
- 断点仍需满足行首禁则；找不到合适标点就原样交给渲染层（宁可孤行，不要半截行）。

## 4. 渲染层（vendor 补丁）

`rewrapOverflowingLines()` 是 Phaser 折不了 CJK 时的最后一跳。它现在在换行时检查新行首字符，
是标点就把上一行末字一起带下去（可连续带多个，例如 `……` / `？！）`）。
补丁登记在 `vendor/phaser-mvvm/PATCHES.md`。

## 7. 已知取舍 / 边界

- 行首禁则只放宽「前引号/前书名号」，**前括号 `（` 不许起行**：剧本里以「（内心独白）」
  开头的整句不受影响（整句第一个字不叫换行），但折行不会把 `（` 甩到行首。
- 翻页页长不再严格等于 `pageChars`：句子边界优先，单页可能短到 45%（约 31 字）；
  行末标点/token 回拉时单页最多 +8 字（68 → 76，仍在 5 行内）。
- 孤行控制只「把断点往前挪一个标点」，不做整段均衡：实在找不到更早的标点时，
  尾行可能只有 2–4 个字（例如「永昌。」），这是可接受的孤行，比把第一行切成 5 个字好。
- 金殿的台词现在也分页；它的时间线（`PalacePlayer`）不受影响——翻页只在场景层，
  不消耗 beat。
