# 美术风格：国风 HD-2D 像素

## 1. 主张

**2D 像素美术 + 电影化光照。** 不搭 3D 场景，用分层视差、体积光、景深、移轴与暗角模拟《八方旅人》式的 HD-2D 纵深；像素本体保持硬边，光效层用柔和渐变。

> **地图探索层的例外**：地图以「游戏素材大师」俯视地图编辑器的**正交俯视**为准（正方形 tile、相机正上方看、无 3/4 立面）；HD-2D 纵深/移轴只用于战斗、CG 与过场，不改变地图透视。
>
> **寝室规则（2026-10-25 重做）**：50×54 俯视整图（1600×1728，按 720 宽显示），四张单人床、中央书桌、北窗、南门；地板/墙/家具都是整图素材，不再用零部件拼。郑卿睡床是运行时 4 帧动画，按剧情替换。

- 纯白 = 解 / 小白 / 梦域本源

- 鎏金 = 梦主的执念与「被看见」的渴望

## 3. 像素规格

- 游戏内 sprite：**2 个设计单位 = 1 个美术像素**（720 设计宽 = 360 美术像素宽）。
- tile 32×32、角色 32×48、敌人 48×64、Boss 96×96 起。
- 纹理过滤：像素本体 NEAREST；UI 文本/光效/景深 LINEAR。
- 图集：1px extrude + 2px padding；九宫格只按整数像素拉伸。
- 字体：标题/数字用方舟像素字体（Ark Pixel，OFL），以 12/16px 美术字号设计，按 2×/3× 整数放大；正文用思源黑体，14–24 设计 px。

## 4. 标题画面

竖屏三段式：

1. 顶部：七枚星座弧线（皇冠、弹弓、宝剑、话筒、玫瑰、铜钱、梦星）。
2. 中段：白色裂隙 + 锈蚀矿工剪影（猩红电子眼）。
3. 下段：学生背影 + 白光匕首；标题与按钮落在下三分之一。

**安全构图**：中心 4:5 区域必须是主体；左右各 15% 可被裁切（20:9 手机会裁）；上下各留 12% 给标题/按钮。

**现场首版**：`title_bg.webp`（AI 生成 → 裁 1440×2560 → 压暗/暗角 → 480×853 降采样 → 56 色量化 → NEAREST 放大）。这是 M0 的首版，不排除 M1 重做。

## 6. 入库流程

```
AI 生成 → 选图 → Pillow/ffmpeg 裁切/压暗 → 像素化（可选）
        → WebP q84–90 → public/assets/img/... → assets:scan → assets:check
        → ASSET-CREDITS.md 记录 jobId/模型/提示词/处理步骤
```

## 7. 不要做

- 不要用非整数倍缩放像素 sprite（会半像素）。
- 不要把长段正文用像素字体（可读性差）。
- 不要让 UI 使用与「墨黑/鎏金/朱红」冲突的高饱和色。
- 不要把矿工的猩红用在非危险元素上。
- 不要在标题安全区外放关键信息。

**日期卡**：金色 520×3 细线由中间向两侧展开；`20x5年9月7日。` 34px 鎏金，`明山县·群英高级中学。` 44px 纸白，两行错峰淡入并上浮。底部「点击继续」使用 65%–100% 的缓慢呼吸，不抢标题。

**播放控制**：右上角两个无边框图标按钮——▶▶「自动播放」（未开启为宣纸白，开启后按钮变鎏金底、图标转墨色）与 ▶|「跳过剧情」，都常驻 28px 图标、56×56 触控区；手动模式每句打完在底部显示「点击继续」的 65%–100% 呼吸提示，自动模式隐藏。逐字提示音为 G5/A5/B5 三档、30ms 的短促「哒」，只在自然逐字时跟随每个字，点「补全整句」不补声。

**动效纪律**：所有动画在引擎内完成，不生成视频；`prefers-reduced-motion` 时关闭震屏、白闪、Ken Burns 与流星扫掠，只保留淡入淡出与文案。正文用固定 640×260 文本框，避免逐字时跳版；全屏图底部压暗到 0.86–0.97，保证亮色校园图上的白字可读。
